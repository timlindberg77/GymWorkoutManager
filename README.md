# GymWorkoutManager
# Workout Tracker är ett enkelt konsolprogram där du kan logga dina träningspass. 
## Vad gör programmet? Du kan skapa en workout, lägga till övningar och sedan titta tillbaka på dina pass i en logg. 

## Kör intruktioner
1. Clona ner repot
2. Kör programet
3. Tryck enter för att starta
4. Använd piltangenter och enter för att navigera
## Huvudmeny 
1. **Ny workout** – skapa ett nytt pass 
2. **Workoutlogg** – se och hantera dina sparade pass 
3. **Avsluta** – stäng programmet 
## Ny workout 
Du väljer först vilken typ av övning du vill lägga till. 
**Styrketräning** 
- Välj muskelgrupp: bröst, rygg, axlar, biceps, triceps, mage eller ben 
- Välj övning, till exempel bänkpress eller squats 
- Ange vikt och antal reps 
**Cardio** 
- Välj aktivitet: löpning, cykling, rodd eller simning 
- Ange antal km och tid 
Varje övning läggs till i din workout (en lista).

## Workoutlogg
- Välj en utav tidigare workouts
- Redigera eller Radera workouten
